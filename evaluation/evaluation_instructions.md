# Human-Evaluation Rubric (Public Summary)

This public note summarizes the expert-review dimensions used in the paper's
human evaluation without releasing the original row-level scoring sheet.

## Rating Dimensions

- `Correctness (1-5)`: whether the draft test case is logically consistent
  with the intended contract behavior at a high level.
- `Relevance (1-5)`: whether the draft test case is useful as a reviewable
  starting point for downstream testing or auditing work.

## Interpretation

- `5`: strong and directly usable with minimal clarification
- `4`: largely sound and useful, with minor issues
- `3`: partially useful but requires noticeable revision
- `2`: weak or substantially incomplete
- `1`: incorrect or not practically useful

## Public-Scope Note

This repository releases only the rubric summary and aggregate statistics.
The original row-level scoring materials and reviewer-specific annotations are
withheld in the public version for confidentiality and data-minimization
reasons.
